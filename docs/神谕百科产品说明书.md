# 神谕百科(Oracle of Games)产品说明书

> 版本:v1.0.0  
> 文档日期:2026-08-13  
> 产品形态:Web 应用

## 一、产品概述

### 1.1 产品定位

**神谕百科**是一款基于 **RAG(检索增强生成)** 技术的游戏知识问答系统。用户上传游戏攻略、角色图鉴、版本更新等资料,AI 即可基于这些资料进行**有依据、可溯源**的智能问答——回答不再凭空发挥,而是检索自用户自己的知识库。

### 1.2 核心价值

| 价值点 | 说明 |
|---|---|
| 私有知识库问答 | 资料只属于你,回答严格基于你上传的内容 |
| 引用可溯源 | 每条回答展示参考来源(条目名 + 相似度 + 可展开全文) |
| 零运营成本 | 文本嵌入完全本地运行,不依赖外部向量服务,无按量费用 |
| 低配可跑 | 2核2G 服务器即可稳定运行,内存占用 ≤ 400MB |

### 1.3 目标用户

- **游戏玩家**:快速查询角色配队、机制、攻略;
- **Wiki / 社区维护者**:把攻略资料沉淀为可问答的知识库;
- **内容运营**:管理游戏资料库,向访客提供智能查询服务。

## 二、核心功能

### 2.1 智能问答

- **流式输出**:回答逐字呈现(打字机效果),可随时停止;
- **多会话管理**:多轮对话自动保存,支持新建 / 切换 / 重命名 / 删除;不同话题开不同会话,切换游戏自动开新会话,互不干扰;
- **按游戏问答**:选择游戏后提问,回答自动基于该游戏的知识库;
- **参考来源**:回答右侧展示命中的资料条目(名称 + 相关度),点击可展开查看完整原文,随时核对;
- **富文本回答**:支持代码高亮、流程图、列表、表格等丰富排版,附一键复制;
- **语音能力**:支持语音提问、语音朗读回答。

### 2.2 知识库管理

- **游戏管理**:为每个游戏建立独立知识库;
- **多格式上传**:支持 `.txt / .md / .pdf / .docx / .xlsx` 等常见文档,拖拽多选,自动解析入库;
- **网址一键入库**:粘贴网页链接,自动抓取标题与正文入库(仅支持公网网页);
- **条目管理**:查看所有资料(标题 / 类型 / 已入库状态 / 分块数),支持关键词搜索高亮、查看全文、删除;
- **检索测试**:输入问题可预览知识库命中情况,方便检查资料是否被正确理解。

### 2.3 系统能力

- **深浅色主题**:一键切换;
- **响应式布局**:PC / 手机自适应;
- **链接直达**:问答页与知识库页均有独立地址,可收藏、可分享。

## 三、界面说明

### 3.1 页面结构

```
/chat   → 智能问答页(三栏)
│   ├── 会话栏:会话列表与操作
│   ├── 聊天区:游戏选择 + 消息 + 输入区
│   └── 参考来源:回答依据的资料卡片
/kb     → 知识库页
    ├── 左侧:游戏列表
    ├── 工具栏:搜索 + 检索测试 + 上传
    └── 条目列表:资料卡片
```

### 3.2 交互要点

- 回车发送、发送中可停止;支持语音输入;
- 消息上悬停出现「复制 / 朗读」按钮(手机端常显);
- 参考来源卡片点击展开完整正文;
- 会话悬停显示「重命名 / 删除」。

## 四、快速上手

1. **建游戏**:知识库页 → 左侧新建游戏(如「原神」);
2. **喂资料**:上传文档(攻略 / 图鉴等),或「网址导入」粘贴 wiki 链接,等待入库完成(条目显示绿色「已入库」);
3. **提问**:智能问答页选择该游戏 → 输入「甘雨怎么配队?」→ 回车,流式回答 + 右侧参考来源;
4. **溯源**:点击参考来源卡片展开完整正文,核对回答依据;
5. **多会话**:新建会话换个话题,历史自动保存,随时回来继续。

## 五、安全与限制

### 5.1 安全设计

- **网址导入防攻击**:仅允许抓取公网网页,自动拦截内网地址;
- **内容安全**:AI 回答中的网页代码类内容经过净化处理,防止恶意脚本;
- **资源限制**:单文件上传 ≤ 20MB,网页抓取有超时与大小限制。

### 5.2 已知限制

- 更换文本理解模型后,已入库资料需重新导入;
- 扫描版 PDF(纯图片)暂不支持文字识别;
- 网页仅支持静态内容,特殊动态页面可能提取不到正文;
- 当前为单用户版本,暂无账号体系。
